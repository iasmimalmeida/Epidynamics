2. Verificação dos pressupostos

2.1 Multicolinearidade

  1. Cálculo do VIF (Variance Inflation Factor): O VIF foi calculado para cada variável preditora no modelo. Isso foi feito após a remoção de colinearidade redundante e tratamento das variáveis para garantir que todas estejam no formato correto (numérico ou categórico).
  2. Variável dependente: dengue_pattern foi temporariamente convertida para numérica apenas para calcular o VIF. Esse ajuste é feito para facilitar a análise de multicolinearidade.
  3. Detecção e remoção de colinearidade: Usamos o findLinearCombos para remover variáveis redundantes, evitando o problema de “aliasing” no modelo, o que ocorre quando variáveis altamente correlacionadas criam dependência linear.

Intrepretação:

  • Valores de VIF < 5: São considerados aceitáveis, indicando baixa multicolinearidade.
  • Valores de VIF entre 5 e 10: Indicariam alguma multicolinearidade, mas ainda podem ser aceitáveis dependendo do contexto.
  • Valores de VIF > 10: Sugerem multicolinearidade.

Resultados:

Quando todas as variáveis em um cálculo do VIF (Variance Inflation Factor) estão muito acima de 10, isso indica alta multicolinearidade entre as variáveis no seu modelo de regressão. Multicolinearidade pode distorcer os coeficientes das variáveis no modelo, dificultando a interpretação e reduzindo a confiabilidade dos resultados.

# Extrair coeficientes e calcular OR manualmente
coeficientes <- coef(model_final)

# Verificar coeficientes extremos antes de exponenciar
coeficientes[coeficientes > 10] <- 10  # Limite superior para evitar valores muito grandes
coeficientes[coeficientes < -10] <- -10  # Limite inferior

exp_coef <- exp(coeficientes)  # Exponenciar coeficientes para obter OR

# Extrair IC95%
se <- summary(model_final)$standard.errors
lower_ci <- exp(coeficientes - 1.96 * se)
upper_ci <- exp(coeficientes + 1.96 * se)

# Criar dataframe dos resultados
results <- as.data.frame(exp_coef)
colnames(results) <- paste0("OR_", colnames(results))
results$Variável <- rownames(results)
rownames(results) <- NULL

colnames(ic_results) <- paste0("Lower_CI_", colnames(ic_results))
ic_results$Variável <- rownames(ic_results)
rownames(ic_results) <- NULL

  left_join(ic_results_upper, by = "Variável") %>%

  mutate(across(starts_with("Upper_CI_"), ~ sprintf("%.2f", .x))) %>%
  pivot_longer(cols = starts_with("OR_"), names_to = "Categoria", values_to = "OR") %>%
  mutate(Categoria = sub("OR_", "", Categoria)) %>%
  left_join(
    final_results %>% pivot_longer(cols = starts_with("Lower_CI_"), names_to = "Categoria", values_to = "Lower_CI") %>% mutate(Categoria = sub("Lower_CI_", "", Categoria)),
    by = c("Variável", "Categoria")
  ) %>%
  left_join(
    final_results %>% pivot_longer(cols = starts_with("Upper_CI_"), names_to = "Categoria", values_to = "Upper_CI") %>% mutate(Categoria = sub("Upper_CI_", "", Categoria)),
    by = c("Variável", "Categoria")
